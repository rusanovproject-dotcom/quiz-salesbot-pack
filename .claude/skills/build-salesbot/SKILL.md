# Сборка продажника

Заполняешь три файла в `engine/salesbot/`: персону, связки, конфиг. Код движка не трогаешь.

**Не начинай без `PROJECT.md`.** Персона собирается из блока «Голос», связки — из блоков «Клиент» и «Узкое место».

## 1. Персона

`persona/persona.md` — шаблон со структурой, заполняешь по блокам. Уходит в системный промпт целиком.

**Голос снимается с живых текстов, а не придумывается.** Нужны настоящие сообщения владельца клиентам. Нет — проси надиктовать голосовое на две минуты и расшифруй.

Из образцов вытаскиваешь наблюдаемое: обращение на «ты» или «вы», длина фраз, чем заменяет смайлы, 5-10 повторяющихся слов, как начинает сообщение, где появляется эмоция, чего никогда не скажет.

«Дружелюбный и профессиональный» — не описание голоса. Это описание ничего.

**Обязательный блок — граница регистра.** Самая частая поломка: на умном собеседнике бот переключается в официальный тон и голос умирает. Запрети это прямым текстом в персоне, иначе модель будет соскальзывать каждый раз.

**Запрети автопилот входа:** «его цитата в кавычках» — это прям в точку. Без явного запрета все получат одинаковое первое сообщение.

Подробно — `playbook/03-персона-и-голос.md`.

## 2. Связки

`persona/connections.md`. Бот берёт ответ про сферу и вырезает **только нужный блок** — целиком файл в промпт не идёт.

Заголовок блока должен содержать слова, которыми люди называют свою сферу в квизе. Матч по подстроке, поэтому пиши несколько синонимов через запятую.

Формат: процесс недели → что снимается → что от этого меняется → кратный скачок → первый шаг за двое суток.

**Главная проверка — тест на пустоту.** Подставь другую профессию. Связка выжила — она пустая.

«Отвечает на заявки в личке» подходит коучу, магазину и мастеру маникюра одинаково. Поднимаешь такую — обязательно добавь вторую, ремесленную: ту, которая невозможна в другом деле.

**Обязательно оставь блок «вне справочника»** — иначе на редкой сфере бот замолчит или начнёт лить общее.

Примеры формы по 13 сферам — `playbook/07-библиотека-связок.md`. Это чужая ниша: бери форму, а не содержание.

## 3. Конфиг

`config.env` (копируется из `config.env.example`). Здесь всё, что бот произносит вслух: цены, ссылки, даты, названия.

**Фактов в персоне быть не должно.** Промпт правится редко, цены меняются часто — иначе бот однажды назовёт цену прошлого месяца.

Отдельно:

- `CLASS_MAP` — ключи те же, что в `quiz.config.js`, значения — слова для поиска в ответе
- `TRACK_RULES` — дорожки оффера. `A` — можно платное, `B` — только бесплатное. Не совпало → `B`
- `LEADS_DIR` — **вне репозитория**: там телефоны и ответы про доход

Пустое поле = бот про это молчит. Это нормально: лучше молчать, чем выдумывать.

## 4. Полигон

Не выпускай к людям без прогона.

```bash
cd engine/salesbot
python3 -m pytest tests/ -q                                      # логика
python3 tools/sim.py tools/personas.json                         # машина, без трат
python3 tools/sim.py tools/personas.json --live > /tmp/live.json # с моделью
python3 tools/check_antigeneric.py /tmp/live.json                # проверка реплик
```

**Замени выдуманных клиентов на своих.** В `tools/personas.json` лежат клиенты из примера про ремонт. Нужны твои: те же типажи, но с ответами из твоего квиза.

Пять типажей закрывают почти всё: холодный скептик, горячий с вопросом о цене, недоверчивый, пришедший без ответов, «дорого, подумаю».

Смотри две вещи:

- **цепочку шагов** (печатается сводкой) — не выпрыгивает ли бот в оффер раньше времени, не застревает ли
- **тексты реплик** — не ушёл ли в общие советы, не выгладился ли голос

Дальше слепой тест: пять реплик бота и пять настоящих сообщений владельца вперемешку. Не отличил — голос собран.

## 5. Запуск

Три ступени, каждая по одному-двум дням:

1. **`TEST_PREFIX=!test`** — бот отвечает только на сообщения с приставкой. Живые подписчики его не видят. Пиши сам, проверяй
2. **`DRAFT_MODE=1`** — ответы приходят владельцу на утверждение, а не человеку. Видно, что бот пишет, до того как это увидят люди
3. **Оба выключены** — боевой режим

Пропустить ступени можно. Стоят они два дня, а спасают репутацию.

**Проверь путь целиком:** пройди свой квиз как клиент, дойди до кнопки, перейди к боту, получи разбор. Квиз работает и бот работает — это ещё не значит, что код доезжает.

## Что уже сделано за тебя

Не переписывай, там оплаченные ошибки: изоляция мозга, разбивка ответа на сообщения, мгновенный ответ до разбора, запись под блокировкой, эскалация при падении модели, лимиты с заглушками вместо тишины, защита от чужого кода.

Подробно — `playbook/08-грабли.md` и `engine/salesbot/README.md`.

## Частые ошибки

| Что | Почему плохо |
|-----|--------------|
| Персона осталась шаблоном | бот говорит ни от чьего лица |
| Голос придуман, а не снят | клиенты чувствуют подделку |
| Связки скопированы из библиотеки | разбор про чужую нишу |
| Факты зашиты в промпт | однажды назовёт старую цену |
| Каталог карточек внутри репозитория | телефоны уедут в публичный доступ |
| Полигон пропущен | половина проблем всплывёт на живых людях |
| Сразу боевой режим | первые сырые ответы увидят клиенты |
