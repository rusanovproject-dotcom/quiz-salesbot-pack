# Пример: студия ремонта под ключ

Заполненный комплект на выдуманной нише — чтобы было видно, как выглядит результат сборки.

```
PROJECT.md      паспорт воронки после интервью
persona.md      персона бота: голос, методология, гварды
connections.md  связки по сферам внутри ниши
config.env.example  цены, ссылки, дорожки офферов
```

Конфиг квиза для этой же ниши лежит в `engine/quiz/quiz.config.js` — он идёт как рабочий пример из коробки.

**Не копируй это себе.** Ниша выдумана, цифры условные, голос принадлежит выдуманному человеку. Смотри на устройство: насколько конкретны вопросы, насколько узнаваемы диагнозы, чем ремесленная связка отличается от общей.

Твой комплект будет другим. Он родится из интервью.
