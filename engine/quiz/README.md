# Движок квиза

Одна HTML-страница без сборки и зависимостей. Весь смысл вынесен в `quiz.config.js` — вопросы, классы, тексты, палитра, куда ведёт кнопка.

```
index.html        механика: экраны, переходы, отправка. Трогать почти не нужно
quiz.config.js    ← здесь ты работаешь
api/quiz.js       прокси до приёмника ответов
vercel.json       конфиг статического деплоя
```

## Посмотреть локально

```bash
python3 -m http.server 8080
# открыть http://127.0.0.1:8080
```

Без приёмника квиз работает целиком: пройдёт до финала, покажет диагноз и выдаст запасной код, который человек может отправить боту руками.

## Как устроен путь

```
фасад → 7 вопросов → пауза в середине → сборка 2 сек → диагноз + кнопка к боту
                                            │
                                            └→ ответы уезжают приёмнику
                                               и ждут человека в диалоге
```

Ответы уходят как `Q1…QN` — по порядку вопросов в конфиге. Бот рассчитывает на этот порядок: `Q1` сегмент, `Q2` сфера, `Q4` боль, `Q5` что берёт первым, `Q6` размер, `Q7` задача текстом. Переставишь вопросы — поменяй и разбор у бота.

Вместе с ответами уезжает `keys` — расшифровка, какой ключ каким вопросом был. Полезно в логах и когда вопросы поменялись.

## Что происходит, если связь оборвалась

Устроено так, чтобы человек не потерялся:

1. Отправка повторяется несколько раз с нарастающей паузой
2. Неотправленное лежит в браузере и уходит при следующем визите
3. Не дошло совсем — в финале виден короткий код, человек отправляет его боту сам, бот поднимает ответы по коду

## Деплой

Подойдёт любой статический хостинг. Если нужен приём ответов — нужна и серверная функция `api/quiz.js`, она есть, например, на Vercel и Netlify.

Переменная окружения: `QUIZ_INTAKE_URL` — адрес твоего приёмника, например `http://198.51.100.10:8087/quiz-submit`.

Не задана — квиз работает, но ответы никуда не едут (запасной вариант с кодом).

## Правки, которые делаются за минуту

| Что | Где |
|-----|-----|
| Поменять вопрос | `questions` в конфиге |
| Поменять диагноз | `classes` |
| Перекрасить | `theme` |
| Убрать технический декор по углам | `theme.hud: false` |
| Не спрашивать телефон | `askPhone: false` |
| Поменять ссылку на бота | `destination.url` |

Добавляешь вопрос — помни, что бот ждёт ответы под своими номерами. Ставь новый вопрос в конец или обнови разбор у бота.
