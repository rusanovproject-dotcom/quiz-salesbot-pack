# Движок продажника

Бот, который встречает человека после квиза, ведёт разбор и доводит до предложения.

## Как устроено

```
транспорт (bot_vk.py / bot_telegram.py)   принять и отправить, больше ничего
      ↓
handle.py        кто пришёл · какие гварды сработали · какой шаг · собрать промпт
      ↓
pipeline.py      машина шагов        objections.py  карта возражений
prompt_builder   сборка промпта      limits.py      предохранители
card.py          карточка человека   escalation.py  карточки владельцу
      ↓
brain.py         вызов модели, разбивка ответа на сообщения
```

**Главный принцип:** код решает, что делать, модель пишет текст. Отдашь выбор шага модели — получишь бота, который продаёт в первом же сообщении.

Из этого следует приятное: всю логику можно прогнать без токенов, без интернета и без единой траты. Чем и занимается полигон.

## Файлы, которые ты заполняешь

| Файл | Что там |
|------|---------|
| `persona/persona.md` | кто говорит, каким голосом, по какой методологии разбирает |
| `persona/connections.md` | связки по сферам: что закрывается и что от этого меняется |
| `config.env` | цены, ссылки, даты, токены. Всё, что бот произносит вслух |

Правило: **фактов в промпте нет**. Промпт правится редко, цены меняются часто — и однажды бот назовёт цену прошлого месяца.

## Запуск

```bash
cp config.env.example config.env    # заполнить
pip install -r requirements.txt     # только для ВКонтакте

python3 intake.py 8087              # приёмник ответов квиза
python3 bot_vk.py                   # или bot_telegram.py
```

## Перед тем как пустить к людям

```bash
python3 -m pytest tests/ -q                                  # логика
python3 tools/sim.py tools/personas.json                     # машина, без трат
python3 tools/sim.py tools/personas.json --live > /tmp/l.json   # с моделью
python3 tools/check_antigeneric.py /tmp/l.json               # проверка реплик
```

Полигон гоняет **настоящий код-путь** на выдуманных клиентах: скептик, горячий, недоверчивый, пришедший без ответов, «дорого, подумаю» и тот, кто сам просит платное. Смотри не только на текст, но и на цепочку шагов — она печатается сводкой. В сводке обязан быть `PITCH` хотя бы у одного: только на нём звучат `OFFER_NAME` и `OFFER_PRICE`, и без него не проверено, как бот продаёт.

Пустые советы у каждой ниши свои. Впиши свои в `tools/antigeneric-custom.txt` (5-7 фраз, по строке) — в шаблоне живых фраз нет, только закомментированный чужой пример. Пока ты не вписал свои, `check_antigeneric.py` работает по встроенному списку чужой ниши и говорит об этом строкой «ВНИМАНИЕ» перед проверкой: «ЧИСТО» в такой прогонке значит только, что чужих фраз не нашлось.

Дальше два предохранителя, оба в `config.env`:

- `DRAFT_MODE=1` — ответы уходят тебе на утверждение, а не человеку. Первые дни держи включённым
- `TEST_PREFIX=!test` — бот отвечает только на сообщения с этой приставкой. Живые подписчики его не видят

Убрал и то и другое — пошёл боевой режим.

## Что уже предусмотрено

- **Чужой код не отдаёт чужую карточку.** Иначе человек пришлёт код приятеля и увидит его ответы про доход
- **Мгновенный ответ до разбора.** Между переходом с квиза и первой репликой модели проходят секунды, и в эти секунды человек сидит в пустом диалоге. Два коротких сообщения закрывают дыру без модели
- **Запись под блокировкой.** Приёмник и бот пишут в один файл: пока модель думала, человек мог оставить телефон. Простая запись затёрла бы его
- **Мозг упал — не молчим.** Человек получает «секунду, вернусь», владелец получает карточку с причиной
- **Предел на человека и общий предел на день.** При срабатывании бот отвечает заглушкой, а не тишиной: молчание на пике = сожжённые лиды
- **Два отказа закрывают диалог.** Третий заход с тем же предложением продаж не приносит, а репутацию портит

## Персональные данные

В карточках лежат телефон и ответ про доход или размер бизнеса.

- `LEADS_DIR` — вне репозитория. По умолчанию `~/quiz-leads`
- В логи телефон уходит только замаскированным
- Бот не произносит доход обратно человеку: этот ответ он давал системе, а не собеседнику
- Дорожка оффера невидима — она решает, что предложить, но вслух не называется никогда

## Смена мессенджера

Транспорт — тонкий слой. `bot_vk.py` и `bot_telegram.py` отличаются только приёмом и отправкой, вся логика общая. Нужен третий мессенджер — копируй любой из двух и меняй две функции.

Код квиза приезжает по-разному: ВКонтакте отдаёт его в `ref` при первом «Начать», Telegram — как аргумент `/start`. В `quiz.config.js` за это отвечает `destination.codeParam`.
