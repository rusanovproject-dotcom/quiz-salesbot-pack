# Quiz Funnel Studio — инструкция для Codex

Этот репозиторий — не автоматический SaaS и не готовая воронка. Это рабочая
методология, набор навыков и два настраиваемых движка, с которыми Codex помогает
владельцу собрать собственные квиз и ИИ-продажника.

## Главный вход

Если пользователь пишет «собери мне квиз-воронку», «хочу квиз», «собери
воронку», просит сделать квиз или ИИ-продажника:

1. Полностью прочитай `adapters/codex/quiz-funnel/SKILL.md`.
2. Затем полностью прочитай `skills/preflight/SKILL.md` и следуй только
   каноническим ссылкам из него.

Порядок вопросов, инициализации, гейтов и все границы безопасности определяет
только канонический `skills/preflight/SKILL.md`; не дублируй и не переизобретай
его процесс.
