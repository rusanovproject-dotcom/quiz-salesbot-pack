# Квиз + ИИ-продажник — конструктор воронки

Заготовка, из которой Claude Code собирает **под тебя** две вещи:

1. **Диагностический сайт** — короткий квиз, который человек проходит за две минуты. На выходе он получает не «спасибо за заявку», а разбор: кто он, что у него узкое место, что чинить первым.
2. **ИИ-продажника** — бота в мессенджере, который видит ответы этого человека и с первого сообщения ведёт живой разбор, а не «здравствуйте, чем могу помочь».

Связка простая: **человек отвечает на вопросы → ответы уезжают боту → бот встречает его уже зная, кто пришёл**. Разбор бесплатный, он и есть подарок за пройденный квиз. Продажа появляется дальше — когда человек уже получил пользу.

---

## Это не готовый продукт. Это заготовка

Внутри лежит рабочий движок и наша фактура: принципы разбора, схема диалога, карта возражений, предохранители, библиотека связок по 13 сферам. Всё это — **скрипты и идеи**, а не то, что нужно скопировать себе один в один.

Вопросы квиза, голос бота, офферы, ниша — **твои**. Их не получится взять из коробки, потому что чужой квиз про чужую нишу конвертит в ноль.

Поэтому первое, что сделает Claude Code, — **допросит тебя**. Не «какой цвет кнопки», а откуда у тебя деньги, кто платит, за что платит, где обрывается путь клиента и что ты продаёшь после разбора. Пока картина не сложится — сборка не начнётся.

## Быстрый старт

```bash
git clone <адрес этого репозитория> моя-воронка
cd моя-воронка
claude
```

Дальше одна фраза в Claude Code:

```
Прочитай START.md и веди меня по нему.
```

Он проведёт по фазам:

| Фаза | Что происходит | Что остаётся у тебя |
|------|----------------|---------------------|
| 0 — Интервью | Задаёт вопросы по одному, вытаскивает нишу, деньги, клиента, узкое место | `PROJECT.md` — паспорт твоей воронки |
| 0.5 — Сверка фактуры | Читает твои материалы сам, ставит утверждениям о клиентах статус достоверности, добирает дыры | Проверенная фактура ЦА в `PROJECT.md` |
| 0.6 — Спрос | Вытаскивает из Вордстата, как люди ищут твоё дело своими словами (нужен ключ Yandex Cloud — можно вернуться позже) | Ключевики и живые формулировки спроса |
| 0.7 — Оффер входа | Семь вариантов оффера в разные нервы, топ-3 на выбор, докрутка | Оффер, ради которого кликают |
| 1 — Квиз | Смысловое ядро (исходы → вопросы) → сборка конфига → упаковка под твой стиль | Живой сайт-квиз по ссылке |
| 2 — Продажник | Собирает персону, связки, шаги диалога, гварды | Бот, который ведёт разбор |
| 2.5 — Заявки, которые не теряются | Выкладывает квиз в интернет и связывает его с приёмником и ботом; журнал заявок в Postgres — по желанию, файловые карточки работают и без него | Публичная ссылка на квиз и база, где лежит каждая заявка |
| 3 — Прогон | Гоняет бота на выдуманных клиентах, ловит генерик и слив | Отчёт, где бот врёт или скучный |
| 4 — Тест офферов | Цикл гипотез по трём точкам воронки (после запуска трафика) | Журнал тестов и растущая конверсия |

Фазы идут по порядку. Прыгать через интервью нельзя — без него сборка выдаст красивый шаблон, который не про тебя.

## Что нужно, чтобы это работало

- **Claude Code** — на нём собирается всё и им же думает бот.
- **Аккаунт мессенджера**, где будет жить бот (сообщество ВКонтакте или бот Telegram).
- **Место под сайт квиза** — подойдёт любой статический хостинг.
- **Сервер под бота** — если хочешь, чтобы отвечал круглосуточно. На старте хватит своего компьютера.

Python 3.11+ и Node не обязательны заранее — Claude Code поставит что нужно по ходу.

---

## Честные границы

- Бот **не гарантирует результат** клиенту и не даёт обещаний за тебя. Он находит точку и первый шаг.
- Бот **не выдумывает цифры**. Нет подтверждённого кейса — говорит без числа.
- Ответы квиза — **персональные данные**. Где их хранить и как не слить, разобрано в `playbook/05-гварды-и-этика.md`. Гейт `scripts/check-pack.sh` не даст закоммитить ключи.
- Оплату бот **не принимает сам** — он доводит до ссылки или до живого разговора.
